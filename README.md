# 기술 임용 자동검증 모의고사 생성기 v2

## v2 핵심
- 실제 임용 원본 2021~2026 A/B 12개(78쪽)를 `official_exam`으로 별도 색인.
- 실제 기출의 문장을 복제하지 않고 **문항 구조**만 8개 패턴으로 일반화.
- A/B 배점 순서를 실제 형식처럼 유지: A 2점×4 + 4점×8, B 2점×2 + 4점×9.
- AI는 정답을 결정하지 않으며, 서브노트의 `answer/evidence/source/page`를 고정한 뒤 표현만 재구성.
- 계산형은 Python이 조건과 정답을 함께 생성. AI 계산값은 채택하지 않음.
- 정답 노출, 근거 부재, 중복, 동일정답 과다반복, 영역 쏠림, 비정상 수치, A/B 교차중복을 자동 차단.
- AI 실패 시 원문 기반 안전 문항으로 자동 대체.
- 실제 기출에서 그림·도면·파형이 중요하므로 패턴 DB에는 표시하되, **검증된 도식 템플릿이 없는 그림은 생성하지 않음**. AI 자유그림 금지.

## 데이터 우선순위
1. 서브노트: 정답/공식/출제 범위
2. 실제 임용 원본: 구조/배점/자료형식/요구행동
3. 기출 풀이: 풀이 보조
4. 모의고사: 스타일 보조

## 의도적으로 막은 문제
- AI가 새 사실/가짜 교육과정 문구/가짜 수치를 만들어 정답 근거로 사용
- 4점 문제를 근거 하나로 억지로 여러 하위문항으로 부풀리기
- 같은 개념·정답의 A/B 반복
- 배점 순서를 무작위로 섞어 실제 시험 형식에서 멀어지는 현상
- 특정 영역만 과도하게 출제
- 그림이 필요한데 존재하지 않는 그림을 지문에서 참조

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
`OPENAI_API_KEY`가 없으면 AI 재작성 없이 안전모드로 동작합니다.

## 남은 제한
- 발명 직접 앵커는 보수적으로만 늘렸기 때문에 아직 다른 영역보다 적습니다. 잘못된 자동 추출을 막기 위해 무리하게 수를 늘리지 않았습니다.
- 전기전자/제조/건설/자동차 계산과 도식 템플릿은 추가 확장이 필요합니다. 현재 검증기 없는 유형은 생성하지 않는 쪽으로 실패합니다.


# FINAL 버전 핵심
- 2020~2026 실제 기술 임용 A/B의 구조를 기준으로 먼저 시험 청사진을 작성
- 2점: 기본 1+1형
- 4점: 1+1+2 / 2+2 / 1+1+1+1 / 1+3 혼합
- 4점이라고 무조건 어려운 두 문제만 내지 않고, 실제 기출처럼 개념→원리→공식/적용으로 부분점수 누적 가능
- 같은 문항유형 3연속 금지, 영역 쏠림 제한
- AI는 여러 원문 앵커를 한 문항으로 편집하지만 정답/evidence/source는 코드가 고정
- AI가 원자료 밖 사실·수치·인용을 만들지 못하도록 프롬프트 제한
- AI 실패 시 부분점수 구조를 유지하는 원문형 안전 문항으로 대체
- 계산형은 Python이 정답을 결정
- 실제 그림 템플릿이 없는 기술 그림은 AI가 자유 생성하지 않음
- 발명 영역은 기술교육론 서브노트 p.106~116의 실제 원문에서 안전 앵커를 추가


# STRICT FINAL
이번 버전은 Terra 출력 샘플에서 확인된 실패 유형을 직접 차단한다.

1. 4점 계산형은 최소 3개 채점요소를 요구하며 기본적으로 1+1+2를 사용한다.
2. 공식 한 번 대입만으로 끝나는 4점 계산형은 검증에서 탈락한다.
3. A/B는 topic/fingerprint뿐 아니라 concept-family가 겹쳐도 탈락한다.
4. 직렬/병렬 스프링처럼 표면적으로 다른 문제도 같은 family이면 A/B 동시 출제하지 않는다.
5. 개념형의 사실 지문은 AI가 쓰지 않는다. 서브노트 evidence를 프로그램이 직접 마스킹해 구성한다.
6. AI(Terra)는 작성 방법과 문항 편집만 담당하며 정답, 사실 전제, 수치 조건을 만들지 않는다.
7. 자료형은 서술/대화/과정/표형을 순환해 단조로움을 줄인다.
8. 정답·해설 PDF에는 부분점수별 채점 기준이 표시된다.
9. 전체 영역 선택 시 한 영역이 과도하게 반복되지 않도록 청사진 단계부터 균등 배치한다.
10. 검증된 그림 템플릿이 없는 회로/도면/기술그림은 AI가 자유 생성하지 않는다.

- 저장본을 영구 삭제할 수 있습니다.
- 수동 수정 시 자동검증 상태를 해제하여 `수정됨`으로 표시합니다.
- `supabase_archive_schema.sql`을 Supabase SQL Editor에서 최초 1회 실행해야 합니다.
- Streamlit Secrets에는 `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `OPENAI_API_KEY`를 설정하세요.

# QUALITY FOCUS v2
- 모든 4점 문항을 최소 3개의 독립 채점요소로 제한했습니다.
- 형식상 4점이지만 실제 요구가 2개뿐인 2+2/1+3 자동 패턴은 잠정 비활성화했습니다.
- 4점 계산형에서 같은 공식을 두 번 채점요소로 세는 방식을 금지했습니다.
- 계산형은 원리/판단 → 중간값 → 최종 계산의 흐름으로 강화했습니다.
- AI 작성방법은 같은 요구 반복을 금지하고, 2점짜리 하위요소에 원문 근거 기반 설명을 요구하도록 강화했습니다.


# AI 출제검토위원 품질우선 모드
이번 버전부터 AI는 문항 작성뿐 아니라 독립적인 품질 심사에도 사용됩니다.

검증 순서:
1. DB/Python이 정답을 먼저 고정
2. AI 관계성 선별기가 가까운 anchor 중 하나의 master concept로 연결 가능한 항목만 선택
3. 문항 작성 AI가 원문 범위 안에서 자료/작성방법 구성
4. Blind reviewer가 정답과 출처를 보지 않고 난도·추론거리·임용 유사성·모호성 평가
5. Grounding reviewer가 고정 정답/근거를 보고 사실성·정답노출·개념응집도 평가
6. Python이 evidence/source/page, 원문 과다복사, 부분점수, 중복을 재검사
7. 섹션 전체 AI 편집 심사
8. A/B 전체 AI 종합 심사

AI는 정답을 결정하거나 바꿀 권한이 없습니다. AI 심사는 veto(탈락)만 할 수 있습니다.
품질우선 모드는 API 호출 수와 생성 시간이 늘어납니다.
