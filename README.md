# 기술 임용 A/B 자동검증 모의고사 생성기

이 버전은 이전의 'GPT가 문제와 정답을 모두 생성'하는 구조를 폐기하고,
**정답을 먼저 고정한 뒤 AI는 문항 표현만 담당**하도록 설계했습니다.

## 내장 DB
사용자가 제공한 영역별 서브노트, 02~25 기출 풀이, 모의고사 문제 형식을 텍스트 색인한 `knowledge.db`가 포함되어 있습니다.
원본 PDF 자체는 배포 파일에 포함하지 않습니다.

## 오류 억제 구조
- 계산형: Python 공식 템플릿이 조건/정답/풀이를 생성
- 개념형: 원문 answer + evidence + source/page를 먼저 고정
- AI: 고정 정답을 바꾸지 않고 임용형 상황문장만 재구성
- 검증 실패: 자동 폐기 또는 보수적 원문 문항으로 대체
- A/B 중복: topic/fingerprint 검사

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Secrets
AI 문장 재구성을 쓸 때만 필요:
```toml
OPENAI_API_KEY="sk-..."
```
API 키가 없어도 AI 없는 안전모드는 실행됩니다.

## 권장 사용
기본은 `엄격 자동검증` 개념입니다. AI는 켜도 정답 결정권이 없습니다.


## 난이도/회로 정책
- 기본 난이도: **적당히 어려움** — 핵심개념 1~2개를 자료·상황에 적용하는 중간~중상 수준
- 과도한 다단계 계산, 함정형 조건, 3개 이상 독립개념 결합은 기본값에서 억제
- 회로 문제: **최대한 제외**가 기본값
- UI에서 `완전 제외 / 최대한 제외 / 허용` 선택 가능
- 전기·전자 영역 자체는 유지하며 비회로 주제를 우선 출제


## v3 변경 사항
- 4점 문항은 단순 공식 1회 대입/용어 하나 맞히기를 금지하고 최소 2단계 사고를 요구
- 계산형 비율을 전체 약 25%로 제한
- 영역을 가능한 한 고르게 순환하여 특정 분야 쏠림 완화
- 목차/단원 제목/서브노트 조각형 앵커 자동 제외
- 회로 문제 기본 제외
- AI는 문항당 최대 2회만 호출
- 기본 모델 GPT-5.6 Luna, reasoning effort low로 속도 개선
- 4점 AI 재작성 실패 시 쉬운 빈칸형으로 강등하지 않고 해당 후보를 폐기


## v4 안정화
- 기존 임용 모의고사의 `자료 → <조건> → <작성 방법>` 구조를 AI 프롬프트에 형식 참고자료로 제공
- 4점 문항만 AI 재구성을 우선 사용하고, 2점은 원문 기반으로 즉시 생성해 속도 단축
- 4점 자리당 API 호출 1회: 재시도 폭주 방지
- AI 문항이 검증에 실패하면 같은 영역의 서로 다른 원문 앵커 2개로 4점 검증형 문항 자동 대체
- 한 문항의 AI 실패 때문에 A/B 전체 생성이 중단되지 않음
- 계산형은 섹션당 약 20%로 제한
- 회로는 `최대한 제외`에서도 실제 생성에서는 제외
- A와 B 사이에 주제뿐 아니라 이미 사용한 정답도 재사용 억제
- 영역을 가능한 한 고르게 순환

## v5 — 기출 구조 청사진 엔진
- 업로드된 기존 모의고사에서 확인되는 형식(자료/상황 + 조건 + 작성방법, 2점·4점 혼합, 계산·도식·오류수정·과정·비교)을 **내용이 아닌 구조만** 청사진으로 사용합니다.
- 시험을 만들기 전에 각 문항의 `영역/배점/문항유형/사고단계`를 먼저 고정합니다.
- 2점도 서브노트 한 줄을 그대로 가리는 문제를 금지하고, 짧은 자료 해석/적용형으로 AI가 재구성합니다.
- 4점은 같은 자료를 바탕으로 연결된 두 가지 이상 작성 요구를 둡니다.
- 유형은 개념 적용/자료 해석/비교/과정/오류수정/원인효과/계산/도식 해석으로 분산합니다.
- 전기·전자는 기본적으로 회로·계산을 배제합니다.
- `요약/정리/단원/목차/서브노트` 등 제목성 정답을 강하게 필터링합니다.
- AI는 정답/evidence/source/page를 변경할 수 없고 생성 후 원문 근거 검증을 다시 통과해야 합니다.
