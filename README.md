# 기술 임용 자동검증 모의고사 생성기 v2

## v2 핵심
- 실제 임용 원본 2021~2026 A/B 12개(78쪽)를 `official_exam`으로 별도 색인.
- 실제 기출의 문장을 복제하지 않고 **문항 구조**만 8개 패턴으로 일반화.
- A/B 배점 순서를 실제 형식처럼 유지: A 2점×4 + 4점×8, B 2점×2 + 4점×9.
- AI는 정답을 결정하지 않으며, 서브노트의 `answer/evidence/source/page`를 고정한 뒤 표현만 재구성.
- 계산형은 Python이 조건과 정답을 함께 생성. AI 계산값은 채택하지 않음.
- 정답 노출, 근거 부재, 중복, 동일정답 과다반복, 영역 쏠림, 비정상 수치, A/B 교차중복을 자동 차단.
- AI 실패 시 원문 기반 안전 문항으로 자동 대체.
- 실제 기출에서 그림·도면·파형이 중요하므로 패턴 DB에는 표시하되, **검증된 도식 템플릿이 없는 그림은 생성하지 않음**. AI 자유그림 금지.

## 데이터 우선순위
1. 서브노트: 정답/공식/출제 범위
2. 실제 임용 원본: 구조/배점/자료형식/요구행동
3. 기출 풀이: 풀이 보조
4. 모의고사: 스타일 보조

## 의도적으로 막은 문제
- AI가 새 사실/가짜 교육과정 문구/가짜 수치를 만들어 정답 근거로 사용
- 4점 문제를 근거 하나로 억지로 여러 하위문항으로 부풀리기
- 같은 개념·정답의 A/B 반복
- 배점 순서를 무작위로 섞어 실제 시험 형식에서 멀어지는 현상
- 특정 영역만 과도하게 출제
- 그림이 필요한데 존재하지 않는 그림을 지문에서 참조

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
`OPENAI_API_KEY`가 없으면 AI 재작성 없이 안전모드로 동작합니다.

## 남은 제한
- 발명 직접 앵커는 보수적으로만 늘렸기 때문에 아직 다른 영역보다 적습니다. 잘못된 자동 추출을 막기 위해 무리하게 수를 늘리지 않았습니다.
- 전기전자/제조/건설/자동차 계산과 도식 템플릿은 추가 확장이 필요합니다. 현재 검증기 없는 유형은 생성하지 않는 쪽으로 실패합니다.


# FINAL 버전 핵심
- 2020~2026 실제 기술 임용 A/B의 구조를 기준으로 먼저 시험 청사진을 작성
- 2점: 기본 1+1형
- 4점: 1+1+2 / 2+2 / 1+1+1+1 / 1+3 혼합
- 4점이라고 무조건 어려운 두 문제만 내지 않고, 실제 기출처럼 개념→원리→공식/적용으로 부분점수 누적 가능
- 같은 문항유형 3연속 금지, 영역 쏠림 제한
- AI는 여러 원문 앵커를 한 문항으로 편집하지만 정답/evidence/source는 코드가 고정
- AI가 원자료 밖 사실·수치·인용을 만들지 못하도록 프롬프트 제한
- AI 실패 시 부분점수 구조를 유지하는 원문형 안전 문항으로 대체
- 계산형은 Python이 정답을 결정
- 실제 그림 템플릿이 없는 기술 그림은 AI가 자유 생성하지 않음
- 발명 영역은 기술교육론 서브노트 p.106~116의 실제 원문에서 안전 앵커를 추가
